# **App Name**: Personal Data Hub

## Core Features:

- Customizable Data Tables: Dynamic table creation allowing users to define columns with various data types (text, number, dropdown, photo, location, etc.).
- Card View: Card-based view displaying data entries in an easily navigable format.
- Advanced Data Filtering: Advanced filtering system allowing users to filter data based on column values.
- PDF Export: Data export to PDF format for printing and archiving purposes.
- Excel Export: Data export to Excel format for further data analysis and manipulation.
- Group Management: Allow users to create, update, and delete groups of people based on separate filters applied to the data, with a dedicated page for group management.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a sense of trust and stability.
- Background color: Very light blue (#E8EAF6), a desaturated version of the primary.
- Accent color: Orange (#FF9800) to highlight important actions and data.
- Body and headline font: 'Inter', a grotesque sans-serif providing a clean and modern look.
- Clean and professional icons for different data types and actions.
- Intuitive layout with clearly defined sections for data tables, filtering, and export options.
- Subtle transitions and animations to enhance user experience when filtering and viewing data.
